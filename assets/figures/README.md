## Reuse pattern

Every externally sourced figure in this directory must retain its original aspect ratio and
include, on the relevant project page: the figure number and caption, a linked source article,
author and journal credit, copyright year, and a linked licence. Use the `figure-attribution`
class for that visible credit and add an `ImageObject` with matching source and licence metadata
to the project page's JSON-LD.
